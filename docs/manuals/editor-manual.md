# Editor Manual

This manual is for staff who update curriculum, resources, files, and member-facing content.

## Main Editing Areas

Editors usually work in:

- `Teach`: curriculum lessons and lesson downloads.
- `Leaders`: shared leader training resources.
- `Leaders > Images`: Bible place photo library.
- `Leaders > Games`: games library.
- `Ministry Leaders`: account-holder ministry resources.
- `Family`: family cards and weekly downloads.
- `Help & FAQs`: help questions shown to members.
- `Media folder`: uploaded files used by lessons and resources.

## Teach Content

Use `Teach` to manage curriculum lessons by volume and term.

Each lesson can include:

- Title.
- Scripture.
- Big Idea.
- Description.
- Year or volume.
- Term or unit.
- Publish date.
- Optional expiry date.
- Status: open or closed.
- School-age files.
- Preschool files.
- Optional podcast title and links.

Open lessons are visible to members when the publish date has arrived and the lesson has not expired. Closed or expired lessons are hidden or treated as inactive.

Use drag and drop to reorder lessons inside a term. Reordering saves the new lesson order for that term.

## Unit Overviews

Each term can have a unit overview. This is the summary content members see around that unit or term.

When editing a unit overview:

- Keep the summary short and clear.
- Check that the overview matches the lessons in the selected term.
- Save after each completed change.

## Lesson Files

Lesson files can be attached directly when adding or editing a lesson, or selected from the media folder.

Common file types include:

- Manuals.
- Worksheets.
- Music files.
- Other downloadable resources.

Use clear file names before uploading. Members see file labels, so avoid internal draft names.

## Media Folder

Use `Media folder` for shared uploaded files.

The media folder is useful when a file will be reused across multiple lessons or when you want to upload first and attach later.

Do not delete or replace files unless you are sure no current resource needs them.

## Leader Resources

Use `Leaders` for shared leader training resources.

Editors can:

- Add sections.
- Add items within sections.
- Edit existing items.
- Reorder sections and items.
- Publish or unpublish content.
- Delete content no longer needed.

## Image Library

Use `Leaders > Images` for Bible place photos.

Each image entry should have:

- Clear title.
- Useful description or context.
- Correct image file.
- Published status.
- Sensible display order.

After saving, use `View library` to check how the image appears to members.

## Games Library

Use `Leaders > Games` for games and activity ideas.

Each game should be written so a leader can quickly understand:

- What the game is.
- Who it suits.
- What equipment is needed.
- How to run it.
- Any safety or setup notes.

After saving, use `View library` to check the member-facing page.

## Family Resources

Use `Family` to manage family cards and weekly downloads.

Check:

- Correct volume.
- Correct week or lesson connection.
- Published status.
- Download links.
- Parent-friendly wording.

## Help & FAQs

Use `Help & FAQs` to update member help content.

Good FAQ answers are:

- Short.
- Direct.
- Friendly.
- Written for church leaders, not developers.

Put payment, renewal, login, team invite, and download questions here when customers ask them repeatedly.

## Publishing Checklist

Before considering an edit finished:

- Check the correct volume and term.
- Check spelling in titles and visible labels.
- Confirm files open or download.
- Confirm the item is published only when ready.
- View the member-facing library or page after saving.
