# New Creation Kids Staff Manuals

These manuals explain how staff should use the New Creation Kids admin area and what the system is doing behind the scenes.

The live business model assumes a working Stripe-style payment gateway. Local or staging builds may still show test-card behaviour, but staff procedures should be written and trained as if card payments, invoices, discounts, and subscriptions are handled by the production payment gateway.

## Manuals

- [Admin manual](./admin-manual.md): For staff with full admin access.
- [Editor manual](./editor-manual.md): For staff updating curriculum, leader, family, image, game, media, and help content.
- [Sales team manual](./sales-team-manual.md): For staff helping churches choose plans, use discounts, understand payment status, and manage customer questions.
- [Behind the scenes](./behind-the-scenes.md): Plain-English explanation of presets, data flow, payment assumptions, publishing, accounts, and storage.

## Access Levels

- Admins can use the full admin console, including products, accounts, discounts, transactions, settings, and admin user access.
- Editors should normally work in content-focused areas: Teach, Leaders, Ministry Leaders, Family, Help & FAQs, Media folder, Games, and Images.
- Sales staff usually need Products, Discounts, Accounts, and Transactions, plus enough content knowledge to explain what customers receive.

Keep these manuals updated whenever the admin navigation, payment gateway, product pricing, subscription rules, or content publishing workflow changes.
